# Contributing

Compatibility reports are welcome because older Intel Mac behaviour can vary by model, macOS version and application build.

## Report a compatibility result

Use the **Compatibility report** issue template and provide:

- Mac model and year
- Model identifier, when available
- Processor architecture
- macOS version
- ChatGPT/Codex build tested
- Whether the app opened
- Whether sign-in and basic Codex functionality worked
- The exact non-sensitive error message, if any

## Safety rules

Do not post:

- Passwords or login codes
- Authentication cookies
- API keys or access tokens
- GitHub or deployment secrets
- Private repository names or contents
- Customer data
- Personal documents

## Pull requests

Pull requests may improve:

- The read-only compatibility checker
- Documentation clarity
- Safety warnings
- Compatibility-report formatting

Do not submit application binaries, archived installers, modified third-party software or direct legacy-build download links to this public repository.

By contributing, you agree that your contribution may be distributed under the repository's MIT Licence.
