# Security policy

## Supported code

Only the current version of `check-my-mac.sh` on the default branch is maintained by this repository.

The checker is designed to be read-only. It reports system and application metadata and runs standard macOS signature checks. It should not install, delete, move or modify applications or user data.

## Reporting a security concern

Do not publish sensitive security findings or personal credentials in a public issue.

For a concern about the repository's checker or documentation, contact the repository owner privately through the public contact method on the Convsrr GitHub profile.

Do not send:

- Passwords
- Login codes
- Authentication cookies
- API keys
- Access tokens
- Private signing material
- Repository or deployment secrets

## Third-party software

This project does not maintain or provide security support for ChatGPT, Codex, macOS or any referenced third-party application build. Security concerns relating to those products should be reported to their respective maintainers.
